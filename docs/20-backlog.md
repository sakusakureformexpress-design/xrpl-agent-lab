## 開発として次にやると強いもの（優先順）

採択を待つ必要が無く、**採択の確率を上げるもの**から並べる。

1. **npm への公開**
   今は clone しないと使えない。`npm i xrpl-leash` で入るようにする。
   採用数は SourceTag で台帳から数えられるので、**成長指標そのものが動き出す**
2. **OWS のポリシーバックエンドとして実装し直す**
   MoonPay 主導・Ripple が公式採用した標準の上に乗る。
   「それ OWS でよくない?」という最大の反論を、構造として消す
3. **Python 版**
   エージェント開発は Python が多い。採用の裾野が変わる
4. **フレームワーク・アダプタ**
   Claude Agent SDK / LangChain など。どの基盤からでも使えるようにする
5. **メインネット対応**
   鍵の取り扱いを固め、セキュリティレビューを通す
