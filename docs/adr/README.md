# 設計判断の記録（ADR）

ADR = Architecture Decision Record。
**「なぜそうなっているのか」を、決めた時点の理由ごと残すための短い文書。**

コードを読めば「どうなっているか」は分かる。分からないのは
**「なぜ他の方法にしなかったのか」**であり、それが分からないと、
後から来た人は同じ検討を最初からやり直すか、悪い方に戻してしまう。

## 書式

各ファイルは次の5つだけ:

| 節 | 内容 |
|---|---|
| **背景** | 何を解こうとしていたか |
| **決定** | 何にしたか |
| **理由** | なぜそれか |
| **却下した案** | 何を検討して、なぜやめたか ← **ここが本体** |
| **結果** | 何が良くなり、何を諦めたか |

## 状態の意味

- **有効** — 今もそうなっている
- **置換** — 別の ADR に置き換わった（どれに置き換わったかを本文に書く）
- **撤回** — やめた
