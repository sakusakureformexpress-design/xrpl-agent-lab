# 0005 — 全取引に `SourceTag` を刻む

状態: 有効
日付: 2026-09-18

## 背景

助成金の成長マイルストーンは「オンチェーン指標」で測られる。
また、採用状況を**自己申告ではなく第三者が検証できる形**で示したい。

## 決定

本ツールが出す全ての取引に

```
SourceTag = 0x4C454153 = 1279607123
```

を刻む。`0x4C454153` は ASCII の `"LEAS"`。

## 理由

`SourceTag` は台帳に残り、誰でも集計できる。
「何件使われたか」をこちらが主張するのではなく、**相手が数えられる**状態にする。

## 却下した案

| 案 | 却下の理由 |
|---|---|
| Memo にツール名を書く | Memo は誰でも書ける。他人が偽装できるし、集計もしづらい |
| 専用の発行体アカウントを経由させる | 余計な依存と手数料が増える |
| 計測しない | 成長マイルストーンを埋められない |

## 結果

- 採用数が台帳から直接数えられる
- ダッシュボードの「台帳に残った記録」も、このタグで自分たちの取引だけを抽出している

## 訂正の経緯

初期実装では `1279414611` を使い、コメントに `"LEAS"` と書いていた。
**これは誤りで、`1279414611 = 0x4C425153 = "LBQS"`** だった。
testnet でしか使っていない段階で発見し、メインネット公開前に修正した。

値とコメントの一致をテストで固定してある。**同じ誤りが再発しないようにするため。**
